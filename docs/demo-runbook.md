# Three-minute controlled demo runbook

## Before recording

1. Run `npm ci`, `npm run verify:env`, `npm test`, and `npm run build`.
2. Run `npm run seed:demo` so the controlled source file is prepared.
3. For the live acceptance recording, connect the controlled creator channel in advance and verify the original/follow-up videos and comments are accessible.
4. Never type credentials during recording.

## Recording

- 0:00-0:20: show the creator-owned original video at the promise and its controlled comments.
- 0:20-0:40: open LORE and point to the visible controlled-data disclosure.
- 0:40-1:00: show the exact quote/timestamp, irrelevant comment exclusion, and confirm the story.
- 1:00-1:35: select prepared creator source, render, play the real MP4, and show validation.
- 1:35-2:00: show caption source, comment IDs, anonymous credit default, and download.
- 2:00-2:35: attach the already-published creator-owned follow-up, inspect drafts, and approve replies.
- 2:35-2:55: show independent reply statuses and mark the story CLOSED.
- 2:55-3:00: “The algorithm remembers performance. LORE remembers the story.”

## Claims

Say “controlled creator-owned scenario” for fixtures. In demo mode, say replies are simulated. Claim a real posted reply only after live mode returns a YouTube reply ID and the thread is refreshed on YouTube.
